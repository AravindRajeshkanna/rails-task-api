# Security policy

**Please do not open a public issue for a vulnerability.** Report it privately through GitHub's
*Security → Report a vulnerability* on this repository, or contact the owner directly.

Include what you found, how to reproduce it (a request with the token removed), and the effect you expect. You will get an
acknowledgement within a few days. Fixes ship with a regression spec and a line in [CHANGELOG.md](CHANGELOG.md).

How the API is defended, control by control, with where each is tested, and the gaps that are known:
[docs/security.md](docs/security.md).
